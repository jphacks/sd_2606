# 税人（ぜいんちゅ）

[![IMAGE ALT TEXT HERE](https://jphacks.com/wp-content/uploads/2026/07/IMG_5316.png)](https://www.youtube.com/watch?v=piaNsc6ilBI)

> 学生に必要な税金・保険・年金の手続きを、あなたの状況から洗い出し、やる順番と流れを見える化する Android アプリ。

## 製品概要
### 背景(製品開発のきっかけ、課題等）
アイデアのきっかけは、開発者自身が20歳になって国民年金保険料の手続きに直面した際、「何から始めればよいかわからない」という課題に直面したこと。
国民健康保険・国民年金・所得税・住民税など、個人に関わる手続きは制度ごとに対象者も期限も異なります。そのため、「何が自分に関係あるのか」を調べるところから難しい。確定申告や学生納付特例の申請漏れなど、知らないまま期限を過ぎて損をするケースも多い。
「手続きはどうすればいいの？」「漏れがないか不安」「制度が変わったらしいけどよくわからない」といった悩みを抱える学生は少なくない。

ターゲットは国民年金やアルバイトの所得税などの対象となる学生。学生は開発者にとって最も身近で、また、学生には自分にどんな手続きが必要なのか、誰に頼ればいいのかが分からない人も少なくないからだ。本アプリでは、学生の税金に対する漠然とした不安を解消することを目的とした。

### 製品説明（具体的な製品の説明）
ユーザーは学生であることを前提に、ルバイトの有無・生年月日・扶養の状況・年収を入力すると、関係する手続き（国民年金・年末調整・親の扶養など）を「必要な手続き」と「関係しそうな手続き」に分けて、関連度順（期限順にも切り替えられる）に表示される。人によって手続きの手順が分岐するものは、例えば国民年金の「学生納付特例を使う／保険料を納める」のように、自分の行う手続きを選ぶと先の手順と金額の目安が出る。各手続きは「何を・どこで・いつ・何を準備して」行うかをステップごとのフローで表示する。
バイト代メーターでは、今年の給料（掛け持ちにも対応）を記録すると次の年収の壁までの残り金額と、このペースで壁を超える月を表示する。働き損になってしまう収入の範囲を教えてくれるので、労働時間を調整して働き損を防げる。また、自分が突破しそうな年収の壁の手続きについて知ることができる。
AIチャットボットで特殊なケースについて相談をすることができる。
タイムラインでは自分に関係する手続きを時系列順にまとめ、手続き期間が近づいたら通知してくれる。手続きが完了したものも履歴に残るから、ちゃんと手続きしたか心配になった時に確認できる。

### 特長
#### 1. 状況を選ぶだけで、関係する手続きを洗い出す
入力は簡単。不要な情報を入力させないのでセキュリティも安心。
難しい条件分岐もボタン一つで完了します。

#### 2. 手続きの流れをタイムラインで可視化
国民年金保険料なら

#### 3. 判定はルール、説明は AI ── 根拠を示しつつ、その人向けのアドバイスを付ける


### 解決出来ること
自分に必要な手続きだけでなく、関係しそうな手続きも提案してくれるから、手続きを取りこぼさない。
手続きについて調べると複雑な文章が出てきてめんどくさく感じてしまうが、シンプルなフローから必要な手続きが分かりやすくなる。
タイムラインで手続きの期間を教えてくれるから、自分で管理しなくても大丈夫。
通知機能で、手続き忘れを防げる。


### 今後の展望
ターゲットを社会人、高齢者と段階的に増やしていきたい。

### 注力したこと（こだわり等）
*「必要な手続き」は自動で、「関係しそうな手続き」は自分に必要な手続きを選んで手動でタイムラインに追加される仕組みにすることで、タイムラインでの表示を整理した。

## 開発技術
### 活用した技術
#### API・データ
* Claude API（手続きごとの個別アドバイス生成）
* 国税庁・日本年金機構・厚生労働省・こども家庭庁の公開情報をもとにした制度データ

#### フレームワーク・ライブラリ・モジュール
* Android: Kotlin / Jetpack Compose / Material 3 / Retrofit / kotlinx.serialization
* バックエンド: Python / FastAPI / Pydantic / Anthropic Python SDK

#### デバイス
* Android スマートフォン
* Raspberry Pi 4（バックエンドのホスティング）

### 独自技術
#### ハッカソンで開発した独自機能・技術
* ユーザーの状態の応じて、各税金が必須・条件次第・無関係を適切に分類すること
* 各税金がユーザーの情報に対して関連度の重み付けを行い、関連度順で表示することができる様にしたこと。（d0506cfc6e863a3f23692c62b5467d9c4c56dd12）
