# 税人（ぜいんちゅ）

[![IMAGE ALT TEXT HERE](https://jphacks.com/wp-content/uploads/2026/07/IMG_5316.png)](https://www.youtube.com/watch?v=piaNsc6ilBI)

> 学生に必要な税金・保険・年金の手続きを、あなたの状況から洗い出し、やる順番と流れを見える化する Android アプリ。

## 製品概要
### 背景（製品開発のきっかけ、課題等）
「扶養から外れると親の税金が上がるらしい」「20歳になったら年金の封筒が来た」──大学生になると、誰からも教わらないまま手続きの当事者になります。

アイデアのきっかけは、メンバー自身が20歳になって国民年金の手続きに直面し、「何から始めればよいかわからない」と困ったことです。学生納付特例は申請したものの、ほかにも払わなければいけない税金がありそうで不安が残りました。年末に今年の収入を数えたら、年収の壁を超えそうになっていたメンバーもいます。

#### 学生の半分以上が「年収の壁」に合わせて働き方を変えている
| 数字 | 内容 | 出典 |
| :---: | --- | :---: |
| **54.6%** | アルバイトをしている大学生のうち、「年収の壁」を意識して就業調整をしている（2025年2月） | [^1] |
| **94.3%** | そのうち「103万円以下」に収まるよう調整している | [^1] |
| **38%** | 「103万円の壁」を意識して労働時間を控えたことがある学生（2025年1月・1,000人） | [^2] |
| **24.4%** | 大学生・大学院生を雇う企業のうち、年末に向けて働き控えの相談を受けた（2025年11月） | [^3] |

「超えないよう忠告された」「超過したぶんの税金は自分で払うよう言われた」「ケンカになってしまった」──103万円を超えて働くことに親から反対された学生は半分にのぼります[^2]。年収の壁は、学生本人の生活費だけでなく、親子の関係や年末のお店の人手にまで響いています。

#### しかも、壁の金額は変化する
| いつから | 何が変わったか | 出典 |
| --- | --- | :---: |
| 2025年分の所得税 | 「特定親族特別控除」ができ、19〜22歳の子の年収が 123万円を超えても、親の控除が段階的に残るようになった | [^4] |
| 2025年10月〜 | 親の健康保険の扶養に入れる年収が、19〜22歳は 130万円未満から 150万円未満になった | [^5] |
| 2026年分の所得税 | 基礎控除などが引き上げられ、所得税がかかり始める年収が 178万円になった | [^6] |

2025年2月の時点では、調整していた学生の 94.3% が「103万円」を基準にしていました[^1]。その後の1年ほどで、壁の金額は上のように何度も変わっています。毎年の改正を追いかけていなければ、昔の「103万円以下に抑える」のままで、損をしないつもりが実は稼げた分を逃していたり、本人の税金・親の控除・親の健康保険のどれかの壁を知らずに越えていたりします。

#### 年収の壁のほかにも、手続きは窓口も期限もばらばら
国民健康保険・国民年金・所得税・住民税など、学生にも関わる手続きはいくつもあり、窓口も期限もそれぞれ違います。例えば国民年金には、20歳になると学生も入ります。学生納付特例を申請すれば在学中の保険料を後回しにできますが、申請が遅れると、申請日より前の事故や病気による障害では障害基礎年金を受け取れない場合があります[^7]。

| 手続き | 窓口 | 期限 |
| --- | --- | --- |
| 国民年金（学生納付特例） | 市区町村の役所・年金事務所・マイナポータル | 毎年度（4月〜翌3月）申請 |
| 年収の壁（親の扶養の届出） | 親の勤務先 | 年末調整（11〜12月）の前 |
| 確定申告 | 税務署（e-Tax） | 翌年2月16日〜3月15日 |

しかも「自分に関係があるか」は年齢・年収・扶養の状況の組み合わせで決まるので、一般向けの解説ページを読んでも自分の答えが出ません。調べるところから難しいので、確定申告や学生納付特例の申請漏れのように、知らないまま期限を過ぎて損をすることも起こります。

そこで本アプリは、ターゲットを学生にしぼりました。学生は私たち開発者にとって最も身近で、自分にどんな手続きが必要なのか、誰に頼ればいいのかが分からない人も少なくないからです。学生の税金や手続きに対する漠然とした不安をなくすことを目指しています。

### 特長
#### 1. 4つ答えるだけで、自分に関わる手続きが分かる
アルバイト・生年月日・扶養の状況・年収に答えると、学生に関係する7つの手続き（年収の壁・親の扶養から外れる・国民年金・確定申告・年末調整・国保に入る・引越し）を「必要な手続き」「関係がありそうな手続き」「対象外の手続き」に分けて出します。カードには **なぜ必要なのか**（例: 「年収 140万円（136万円超）、親の扶養に入っている」）も表示します。

分からない項目は「まだ分からない」として判定し、判定に必要になった手続きのカードでだけ聞き直します。並びは関連度順と期限順を切り替えられます。

#### 2. 自分に当てはまった手順を、やる順に
各手続きは「何を・どこで・いつ・何を持って」をステップごとのタイムラインで見せます。19〜22歳だけに必要な手順や親の扶養に入っている人だけの手順など、**当てはまらないステップは表示しません**。国民年金の「学生納付特例を使う／保険料を納める」のように、選ぶとその先の手順と金額の目安が出ます。

#### 3. バイト代メーターで年収の壁に気づく
給料を支給日ごとに記録すると、今年の合計をビーカーに積み、**次の年収の壁まであといくらか**と **このペースだと何月に超えるか** を出します。税金の目安や、天引きされた所得税が戻る見込みも分かり、壁からその壁に関係する手続きへ移れます。


#### 4. AIチャットボットがユーザーの悩みに寄り添う
Claude に、分からない手続きのことを質問できます。アプリが判定した結果と回答をあらかじめ AI に伝えるので、「私は20歳で年収は…」と書かなくてよく、質問の例を押すだけで聞けます。答えが本人の状況で変わるのにそれが分からないときは、場合分けで長く答えるのではなく **聞き返し**、選んだ答えは判定にも反映されます。

### 解決出来ること
- 「自分に何が関係あるのか」を調べる手間がなくなる
- 期限と手順が分かるので、知らないまま期限を過ぎて損をすることを防げる
- 年収の壁を年末に気づくのではなく、超える前に気づいて働き方を決められる
- 回答を端末の外に出さないので、年収や扶養の状況を安心して入力できる


### 今後の展望
ターゲットを社会人、高齢者と段階的に広げていき、最終的には多くのユーザーに利用してもらいたい。

### 注力したこと（こだわり等）
* 「必要な手続き」は自動で、「関係しそうな手続き」は自分に必要な手続きを選んで手動でタイムラインに追加される仕組みにすることで、タイムラインでの表示を整理した。
* 記入が必要な項目を最低限にした。ユーザーは少ないストレスで検索結果を得ることができるし、余計な個人情報を取得される心配がない。特に、アルバイトを掛け持ちしている場合、複雑な条件分けによって必要な手続きが変わる。判別を簡略化させるために、「アルバイトの有無」「年収」から自分に不必要な手続きを非表示→年収130万円以上なら「アルバイトを掛け持ちしている/していない」を選択するだけで自分に必要な手続きを表示するようにした。
* 画面に表示される文字数は必要最低限にした。文字数が多くて読むのが大変なことにより発生する、手続きへの忌避感を軽減させる。
* アプリを信頼して使ってもらうために、学生に発生し得る手続きについて可能な限り全て網羅した。これにより、学生は手続きの漏れがないかと心配する必要がなくなる。

## 開発技術
### 活用した技術
#### API・データ
* Claude API（「AIに質問」の回答と聞き返し）
* 国税庁・日本年金機構・厚生労働省・こども家庭庁の公開情報をもとにした制度データ

#### フレームワーク・ライブラリ・モジュール
* Android: Kotlin / Jetpack Compose / Material 3 / Room / Retrofit / kotlinx.serialization
* バックエンド: Python / FastAPI / Pydantic / Anthropic Python SDK

#### デバイス
* Android スマートフォン
* Raspberry Pi 4（バックエンドのホスティング）

### 独自技術
#### ハッカソンで開発した独自機能・技術
* ユーザーの状態に応じて、各税金が必須・条件次第・無関係を適切に分類すること
* 各税金がユーザーの情報に対して関連度の重み付けを行い、関連度順で表示することができる様にしたこと。（[d0506cf](https://github.com/jphacks/sd_2606/commit/d0506cfc6e863a3f23692c62b5467d9c4c56dd12)）
